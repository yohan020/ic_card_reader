# 유이레일 패스 데이터 고지

- 상품: 유이레일 1일·2일 프리 승차권, 성인 24시간 ¥1,000 / 48시간 ¥1,800 (2026-09-18 확인)
- 적용 범위: 유이레일 전 19개 역
- 앱 포함 데이터: 19개 역과 342개 방향별 성인 일반 편도 운임
- 역 순서·영업거리: Japanese Wikipedia `沖縄都市モノレール線`의 CC BY-SA 4.0 데이터를 정규화하여 사용한다.
- 운임: 유이레일 공식 운임 규칙과 역별 운임 페이지를 대조한 파생 운임표다. 공식 전체 운임표·PDF·로고는 앱에 포함하지 않는다.

공식 확인 링크:

- https://www.yui-rail.co.jp/ticketinfo-ticket/ticketinfo/1day-pass/
- https://www.yui-rail.co.jp/ticketinfo-ticket/ticketinfo/ticket/
- https://www.yui-rail.co.jp/routemap/

라이선스:

- https://ja.wikipedia.org/wiki/沖縄都市モノレール線
- https://creativecommons.org/licenses/by-sa/4.0/

제한: 이 비교는 성인 일반 운임만 합산한다. OKICA 등 결제수단별 할인, 다른 회사 환승, 소아요금과 실제 구매 조건은 포함하지 않으므로 이용 전 공식 안내를 확인해야 한다.
