# 게이한 데이터 출처 및 배포 메모

기준일: 2026-08-24

## 결론

현재 패키지의 **게이한 운임 생성 파이프라인에서는 `keihan.co.jp`를 생산 데이터 출처로 사용하지 않는다.**

게이한 데이터는 다음 구조로 다시 생성했다.

```text
Wikipedia / 駅データ.jp
  → 역·노선·인접 영업거리 사실값

국토교통성(MLIT)
  → 2025-10-01 이후 거리별 보통운임
  → 中之島線 가산운임 유지 여부 및 60엔 정보

독립 계산 코드
  → 최단 영업거리
  → 거리별 운임 적용
  → 中之島線 +60엔
  → 大江橋=淀屋橋 / なにわ橋=北浜 운임동등 규칙
  → 최종 역쌍 운임
```

## 사용 출처

### 京阪本線 영업거리
- https://ja.wikipedia.org/wiki/%E4%BA%AC%E9%98%AA%E6%9C%AC%E7%B7%9A
- Japanese Wikipedia / CC BY-SA 4.0
- 전체 공식 운임표를 복제하지 않고 인접 영업거리 사실값만 정규화

### 京阪中之島線 영업거리 및 운임동등 규칙
- https://ja.wikipedia.org/wiki/%E4%BA%AC%E9%98%AA%E4%B8%AD%E4%B9%8B%E5%B3%B6%E7%B7%9A
- Japanese Wikipedia / CC BY-SA 4.0
- `大江橋`은 `淀屋橋`, `なにわ橋`은 `北浜`과 천満橋以東 운임을 동등하게 계산하는 규칙을 로직으로 구현

### 거리별 보통운임
- https://www.mlit.go.jp/common/001879895.pdf
- 국토교통성 공개자료
- 2025-10-01 개정 운임 구간을 계산 규칙으로 사용

### 中之島線 +60엔
- https://www.mlit.go.jp/common/001879895.pdf
- https://www.mlit.go.jp/common/001287195.pdf
- 2025년 자료에서 가산운임을 변경하지 않는다고 확인하고, 국토교통성 가산운임 현황 자료의 60엔 값을 적용

### 역/노선 마스터 대체 출처
- 駅データ.jp: https://ekidata.jp/agreement.php
- 이용약관상 상업·비상업 이용, 가공 및 제3자 제공 허용
- 필요 시 station master를 이 데이터로 교체 가능

## 라이선스 처리

Wikipedia 텍스트/표현물을 그대로 재배포하지 않는다.
패키지에는 자체 컬럼 구조로 정규화한 인접거리 사실값과 독립 계산 결과만 저장한다.

보수적으로 다음 attribution을 유지한다.

> 일부 게이한 노선·영업거리 정보는 Wikipedia contributors의 공개 정보를 참고하여 정규화했습니다. Wikipedia 콘텐츠는 CC BY-SA 4.0 및 Wikimedia 이용조건에 따라 제공됩니다. 운임 규칙은 일본 국토교통성 공개자료를 기준으로 독립 계산했습니다.

`keihan_source_provenance_2026.csv`에 구체적인 출처를 함께 기록한다.

## 게이한 공식 사이트 이용약관 리스크

게이한 공식 사이트는 **생산 데이터 생성원에서 제거**했다.
따라서 이전 버전에서 문제였던 “게이한 사이트에서 얻은 데이터·정보를 상용 DB로 재배포”하는 구조는 더 이상 사용하지 않는다.

단, 이는 법률 자문이나 무위험 보장을 의미하지 않는다.
앱 출시 시에는:
- 원본 공식 PDF/표/로고/이미지 미포함
- 출처 메타데이터 유지
- Wikipedia 귀속 및 라이선스 고지 유지
- 정부 공개자료 출처 표시 유지
를 권장한다.
