# Agent Instructions

Before working in this repository, read and follow the project-wide rules in `docs/agent/RULES.md`.

When the user adds, changes, or removes a persistent agent working rule, update `docs/agent/RULES.md` in the same task. Keep product progress in `docs/DEVELOPMENT_STATUS.md`, not in this file.

## Frontend UI/UX work

For any task that creates a new frontend UI/UX or changes an existing screen's visual design, load and use the installed `frontend-design` skill by default. Apply it only to visual design work such as layout, spacing, typography, color, icons, and motion. Do not change feature logic, data handling, navigation behavior, or other existing behavior unless the user explicitly requests that functional change.
