# 네 주요 화면 UI 평가

방법: Android 네이티브 디자인 평가 단독. impeccable의 Operate/기존 구조 보존 기준. 웹 detector·브라우저 overlay·서브에이전트는 네이티브 평가에 적용하지 않는다.

## 범위와 한계

사용자가 제공한 2026-11-12 15:06의 설정/도구/빈 이용내역/홈 스크린샷 네 장을 평가했다. 사용자가 제공한 실제 렌더 결과를 근거로 하며 실행 중 앱 조작이나 새로운 빌드를 수행하지 않았다. 카드 스캔 후 잔액/채워진 이용내역·다크/영어/큰 글씨·스크린리더/터치 성공률·오류 복구는 평가하지 않았다. 가독성/색 대비 합격이나 동작 오류를 스크린샷만으로 단정하지 않는다.

## 총평

하늘색 포인트·차가운 밝은 배경·흰 카드·하단 네 탭이 잘 연결된다. 설정 개선 방향은 유지할 가치가 있다. 전면 재설계보다는 화면별 정보 밀도와 상태별 우선순위를 정리할 단계다. 카드 스캔이라는 제품 성격은 홈의 카드 그림에 드러나지만, 큰 둥근 카드와 큰 아이콘을 반복하는 다른 화면에서는 제품 고유성이 약하다. 모든 탭을 동일한 구조로 바꾸기보다는 색·글꼴·버튼 문법을 공유하고 용도에 맞춰 밀도를 달리하는 것이 적합하다.

## 화면별

- 설정: 네 화면 중 가장 정돈됐다. 테마와 두 언어 항목의 통합, 좌측 제목/우측 현재 값, 작은 무배경 정보 아이콘, 연한 구분선이 효과적이다. 추가로 크게 축소할 필요는 없다. 긴 출처 설명은 부가 정보로 무게를 낮춘 상태를 유지한다. 스크롤이 필요한 개인정보 섹션 자체는 문제가 아니다.
- 홈: 스캔 주 행동과 잔액 비교 보조 행동의 위계가 분명하고 NFC 상태/도움말도 있다. 그림과 그 주변 여백의 비중이 커 반복 사용자에게는 안내 화면처럼 느껴질 수 있다. 그림과 상단 여백을 조금 줄여 스캔 버튼과 최근 내역을 더 빨리 보게 하는 방향을 우선 검토한다. 제품 성격을 주는 그림을 삭제하거나 버튼을 작게 만드는 것은 권장하지 않는다.
- 빈 이용내역: 잔액 없음과 이용내역 없음이 큰 카드 두 개로 같은 미스캔 상태를 반복한다. 다섯 필터도 아직 읽은 기록이 없는 상태에서는 유용성이 낮다. 상단에 스캔 아이콘이 이미 있지만 본문은 홈에서 스캔하라고 안내해 가능한 행동을 덜 분명하게 전달한다. 빈 상태를 하나의 안내/주 행동으로 정리하고 잔액 강조/필터는 스캔 후 정보 계층과 구분하는 안이 가장 효과적이다. 실제 버튼/노출 동작 변경은 별도 승인 후에만 구현한다.
- 도구: 기능 이름과 선형 아이콘은 명확하다. 현재 세 기능에는 2열의 큰 카드가 정보량에 비해 무겁고, 아이콘 아래 간격과 긴 설명이 카드 높이를 키운다. 3개라는 홀수 자체나 남는 공간 자체를 오류로 취급하지 않는다. 현재 개수에는 가로형 목록이 더 효율적일 수 있고, 향후 여러 기능 추가를 중시하면 그리드를 유지하되 카드 높이·아이콘 배경·내부 간격만 줄이는 대안이 있다. 빈 네 번째 카드를 억지로 만들지 않는다.

## 우선순위

1. P2 빈 이용내역의 중복 상태/행동 안내 정리. 가장 눈에 띄는 사용성 개선 후보. onboard/distill 범위.
2. P2 도구 카드 밀도 개선. 현재 3개 기능을 더 빨리 훑을 수 있도록 layout 범위.
3. P3 홈 그림과 주변 여백의 비중 축소. CTA 크기는 유지하며 layout/polish 범위.
4. P3 전역 글꼴 무게 체계 점검. 설정의 보통 행과 다른 화면의 굵은 보조 문구를 비교하되 제목/금액/CTA의 역할별 차이는 유지한다. typeset 범위.

기능을 막는 P0/P1 문제는 이 네 장에서 확인되지 않았다. 실제 동작이 정상임을 증명하는 것은 아니다.

## 사용자 관점

- 처음 쓰는 사용자: 홈의 스캔 버튼은 명확하지만 빈 이용내역은 오른쪽 상단 아이콘과 본문의 홈 이동 안내가 서로 다른 경로를 제시한다.
- 이동 중 반복 사용자: 홈에서 스캔 버튼을 찾는 데 그림을 지나쳐야 한다. 도구는 한눈에 기능을 읽을 수 있지만 카드 높이가 커 훑는 효율이 낮다.
- 큰 글씨/보조기술 사용자: 이 네 장으로 터치 영역·TalkBack·확대 대응의 합격/실패를 판단할 수 없다. 디자인을 일괄 작게 만드는 대신 불필요한 장식·간격을 줄이는 것이 안전하다.

## 다음 결정

### 이용내역 후속 평가 — 미스캔/스캔 후

스캔 후 사진을 추가로 확인했다. 브랜드 아이콘·큰 잔액·날짜별 그룹·충전의 녹색 표시는 유지할 가치가 있다. 잔액 강조를 없애거나 작은 우측 숫자로 되돌리는 방향은 권장하지 않는다.

- 미스캔: 지갑/잔액 대시와 별도의 빈 내역 카드가 같은 상태를 반복한다. 하나의 안내/명확한 스캔 행동으로 통합하고 데이터 없는 필터/합계를 줄이는 방향을 권장한다. 스캔 성공이지만 읽을 내역이 없는 경우와 필터 결과0건은 미스캔과 다른 상태로 유지해야 한다.
- 스캔 후: 브랜드 아이콘과 잔액을 세로로 쌓은 카드 비중이 커 필터·합계까지 지나야 첫 내역이 보인다. 금액의 중심성을 유지하되 좌측 카드 아이콘+우측 큰 잔액 등의 가로 구성을 후보로 검토하면 상단 높이를 줄일 수 있다. 현 세로 구조를 유지하는 보수안은 카드 내부 세로 간격부터 조정한다. 사용자 승인 전 기존 카드 크기를 다시 바꾸지 않는다.
- 최우선 행 개선: 현재 일반 폭에서는 경로와 이용 후 잔액이 같은 Row의 두 Expanded를 나눠 사용하고, 경로는 maxLines1/ellipsis다. 긴 영문 역명은 출발역만 보여 도착역을 파악하기 어렵다. 금액/거래유형은 상단에 유지하고 경로를 다음 줄의 가로 전체로 분리해 출발/도착을 최대2줄로 보여주는 안이 유용하다. 이용 후 잔액은 더 낮은 우선순위로 별도 배치한다. 거래 아이콘 크기·날짜별 묶음은 유지한다.
- 필터/지출 합계는 기능이 명확하므로 없애기보다 시각 무게를 잔액보다 낮게 유지한다. 지출 합계의 접기/확장 구조는 유지한다.

권장 순서: 미스캔 안내 통합 → 내역 행의 출발/도착 가독성 → 잔액 강조를 유지한 상단 높이 최적화. 이번에는 판단만 했으며 UI 소스는 바꾸지 않았다. 실제 카드 내역이 담긴 새 사진은 공개 PR에 포함하지 않는다.

우선 대상은 빈 이용내역/도구/홈 중 선택하고, 기존 구조의 간격 조정만 할지 빈 상태·도구의 배치 후보까지 볼지 사용자 결정을 받는다. 개선 작업을 자동으로 TODO에 등록하거나 앱에 반영하지 않는다.

## 기록

사용자 제공 사진에 근거한 검토 문서만 작성했다. source target slug는 lib-src-app-dart이며 ignore 목록 파일은 없었다. 장기 취향/외관 장부는 수정하지 않았다. 프로젝트 문서 규칙에 따라 이 문서에 평가를 보관하며 별도 .impeccable snapshot/trend는 생성하지 않았다. 앱 소스·버전·테스트·설정·빌드·배포 변경 없음.
