개인정보처리방침

일본 교통카드 리더 · 시행일 2026년 10월 27일

카드 정보는 기본적으로 기기 안에서 처리됩니다. 교통카드 이용내역은 NFC로 읽어 화면에 표시하며 영구 저장하지 않습니다. 카드 IDm 원문은 NFC 통신 중에만 일시적으로 사용하고 저장·표시·전송하지 않습니다.

1. NFC 사용 목적

앱은 사용자가 스캔을 시작했을 때 일본 교통계 IC 카드의 최근 이용내역과 카드 종류를 확인하기 위해 NFC 기능을 사용합니다. 별도 카드 인식 문의에서는 동의한 경우 최소 메타데이터만 확인합니다. 앱은 카드에 정보를 기록하거나 변경하지 않습니다.

2. 기기 안에서 처리하는 정보

최근 이용내역의 원본 16바이트 기록, 날짜, 거래 유형, 역 코드·역명, 금액과 잔액을 기기 안에서 해석해 표시합니다. 이용내역은 영구 저장하지 않으며 일반 스캔에서 다른 카드를 읽으면 현재 결과로 교체됩니다.

여러 카드 잔액 비교에서는 최대 10장의 이름·잔액·확인 시각과 이용내역을 비교 화면의 메모리에서만 보관합니다. 같은 카드 구분에는 매 비교마다 생성한 무작위 키로 만든 세션 한정 비교값을 사용하며 IDm 원문을 보관하지 않습니다. 비교값·키·카드 이름은 서버나 파일에 저장·전송하지 않고 비교 종료 또는 앱 프로세스 종료 시 정리합니다. 개별 카드 삭제 시 해당 비교 정보도 제거합니다. 비교용 스캔은 홈의 기존 카드 결과를 변경하지 않습니다.

3. 오류 제보 시 전송하는 정보

오류 제보는 선택 사항입니다. 사용자가 전송 전 미리보기를 확인하고 명시적으로 동의한 경우에만 다음 정보를 Supabase로 전송합니다.

  • 선택한 이용내역 1건의 원본 16바이트 기록
  • 지역·노선·역 코드와 현재 해석 및 사용자가 제안한 해석
  • 거래 유형, 이용 날짜, 잔액과 계산 금액
  • 사용자가 제보 유형에 따라 입력한 역 이름·도시·노선, 버스 회사명·운행 도시/지역 또는 제보 설명
  • 사용자가 직접 입력한 추가 설명
  • 앱·파서·역 데이터베이스 버전, 플랫폼과 OS 버전
  • 앱에서 생성한 익명 제보 번호

전송된 내용은 오류 확인과 앱 개선을 위해 사용합니다.

별도 카드 인식 문의

이용내역 제보와 별개의 선택 기능입니다. 진단 스캔에 동의하면 시스템 코드·제조 정보(PMm)·허용된 일부 서비스 존재 여부·통신 오류 종류만 기기에서 확인합니다. 카드 전체나 서비스 본문은 읽지 않습니다.

전송 항목 미리보기·목적·보관 기간을 확인하고 별도로 명시적 동의를 한 경우에만 최소 진단, 입력한 카드 종류·문제 설명, 앱/OS 버전·플랫폼·접수 번호·동의 문서 버전을 Supabase로 전송합니다. 카드 종류 구분·읽기 오류 개선에 사용합니다. IDm·카드번호·잔액·이용내역·전체 덤프는 포함하지 않습니다. 입력란에도 개인정보를 적지 않도록 안내합니다. 내용을 변경하면 동의를 다시 확인하며, 화면을 나가면 앱에 문의 내용을 남기지 않습니다.

카드 인식 문의는 같은 익명 인증 기반 접수 제한을 적용하고 처리 완료 후 1년 뒤 월간 작업에서 삭제합니다. 검토 중인 문의는 유지합니다. 접수 번호를 문의 이메일로 알려 삭제를 요청할 수 있습니다.

4. 전송하지 않는 정보

카드 IDm 원문, 선택하지 않은 다른 이용내역, 이름, 이메일 주소, 기기 고유 식별자, 현재 위치와 전체 이동 경로는 오류 제보 데이터에 포함하지 않습니다.

5. 외부 처리 서비스

오류 제보 접수에는 Supabase의 익명 인증, Edge Function과 PostgreSQL 데이터베이스를 사용합니다. 익명 인증 ID는 10분당 최대 5건의 반복 제보 제한과 악성 제보 차단을 위해 서버 내부에서만 제보와 연결하며, 관리자 화면에는 표시하지 않습니다. 네트워크 연결 과정의 기술 정보는 Supabase의 서비스 운영 및 보안 정책에 따라 처리될 수 있습니다.

5-1. Google 지도

철도 이용내역 상세를 열면 인터넷 연결·역 위치·지도 설정을 확인한 경우 Google Maps SDK 지도를 자동으로 표시합니다. 복합역·구간은 후보 위치를 표시합니다. 표시할 역의 좌표와 주변 영역이 지도 요청에 사용됩니다. Google은 IP 주소, 기기·운영체제·SDK 정보, 지도 SDK 전용 가명 식별값, 진단·사용 정보를 처리할 수 있습니다. 현재 위치 권한은 요청하지 않으며 카드 IDm·카드번호·잔액·이용내역 원문은 지도 SDK에 전달하지 않습니다.

인터넷 연결이 확인되지 않으면 지도를 표시하지 않으며, 연결 후 지도 새로고침으로 다시 시도할 수 있습니다. 연결 상태는 Android 네트워크 기능 정보로 기기에서 확인하며 별도 확인 서버에 요청하지 않습니다. 지도 표시 중단이나 새로고침은 이미 발생한 지도 요청을 취소하거나 삭제하는 것은 아닙니다. 지도 연결 없이도 카드 읽기와 이용내역 목록은 사용할 수 있습니다. 앱은 지도 이용내역을 별도로 저장하지 않습니다. Google의 처리·보관·삭제 기준에는 Google 개인정보처리방침이 적용됩니다. Maps SDK 데이터 공개 안내도 참고할 수 있습니다. 역 좌표는 앱에 포함한 Wikidata CC0 자료를 사용하며 온라인 역 검색·경로 검색은 하지 않습니다.

6. 역 코드 데이터

역명 조회에는 사용 허가를 받아 앱에 함께 배포하는 Yoiko 역 코드 데이터를 사용합니다. 조회는 기기 안에서 수행되며 역명을 확인하기 위해 카드 기록을 외부 서버로 보내지 않습니다.

7. 보관과 삭제

기기에서 읽은 이용내역은 앱이 영구 저장하지 않습니다. 선택적으로 전송된 오류 제보 중 해결된 문의와 검토 이력은 해결 시점부터 1년간 보관한 뒤 매월 자동 삭제합니다. 미처리 제보는 자동 삭제하지 않습니다. 악성 제보 차단에 쓰는 익명 인증 ID는 서버 보안 목적으로만 유지하며, 법령상 보존 의무가 있는 경우에는 해당 기간 동안 보관할 수 있습니다.

8. 이용자의 선택

오류 제보나 카드 인식 문의를 전송하지 않아도 NFC 읽기와 이용내역 확인 기능을 사용할 수 있습니다. 전송 전 화면에서 실제 전송 항목을 확인할 수 있으며, 해당 전송에 동의하지 않으면 제보·문의 데이터는 전송하지 않습니다. Google 지도는 위 5-1항에 안내한 조건에서 자동으로 연결되며, 지도 서비스의 데이터 처리는 제보·문의 전송과 별개입니다.
