# 일본 교통카드 리더 개인정보처리방침

- 시행일: 2026년 11월 13일

- 공개 주소: <https://yohan020.github.io/ic_card_reader/>
- 영문 방침: [English](PRIVACY_POLICY_EN.md)

## 1. NFC 사용 목적

앱은 사용자가 스캔을 시작했을 때 일본 교통계 IC 카드의 최근 이용내역과 카드 종류를 확인하기 위해 NFC 기능을 사용합니다. 별도 카드 인식 문의에서는 동의한 경우 최소 메타데이터만 확인합니다. 앱은 카드에 정보를 기록하거나 변경하지 않습니다.

## 2. 기기 안에서 처리하는 정보

최근 이용내역의 원본 16바이트 기록, 날짜, 거래 유형, 역 코드·역명, 금액과 잔액을 기기 안에서 해석해 표시합니다. 이용내역은 영구 저장하지 않으며 일반 스캔에서 다른 카드를 읽으면 현재 결과로 교체됩니다. 카드 IDm 원문은 NFC 통신 중에만 일시적으로 사용하고 저장·로그·화면 표시·서버 전송을 하지 않습니다.

여러 카드 잔액 비교에서는 최대 10장의 이름·잔액·확인 시각과 이용내역을 비교 화면의 메모리에서만 보관합니다. 같은 카드를 구분하기 위해 비교를 시작할 때 생성한 무작위 키와 카드 IDm으로 세션 한정 비교값을 만들며, IDm 원문을 보관하지 않습니다. 비교값·무작위 키·입력한 카드 이름은 서버나 파일에 저장·전송하지 않고 비교 종료 또는 앱 프로세스 종료 시 정리합니다. 개별 카드 삭제 시 해당 카드의 비교 정보도 제거합니다. 일반 스캔 결과는 비교용 스캔으로 교체하지 않습니다.

### 선택적 CSV 내보내기

사용자가 CSV 내보내기를 선택한 경우에만 현재 보고 있는 카드의 전체 또는 현재 필터 이용내역을 앱 언어·역명 설정에 맞춰 파일로 만듭니다. 표시된 날짜·거래 유형·승하차역·설명·금액·잔액과 금액 상태를 포함하며 카드 원본 기록·IDm·역 데이터베이스 파일·비교 식별값은 포함하지 않습니다. Android 시스템 파일 선택 창에서 저장 위치를 직접 선택합니다. 앱 내부에는 CSV를 보관하거나 앱 운영자에게 자동 전송하지 않습니다. 내보낸 파일은 세션 종료 후에도 남으며 사용자가 직접 관리·삭제합니다. 클라우드 문서 제공자를 선택하면 해당 제공자의 약관에 따라 업로드될 수 있습니다. 저장 위치 선택 전 취소하면 파일을 저장하지 않으며, 쓰기 실패 시 선택한 위치에 빈 파일이나 일부 파일이 남을 수 있습니다. CSV는 정식 영수증이 아니며 카드에서 사라진 과거 기록은 복구하지 못합니다.

## 3. 오류 제보 시 전송하는 정보

오류 제보는 선택 사항입니다. 사용자가 전송 전 미리보기를 확인하고 명시적으로 동의한 경우에만 다음 정보를 Supabase로 전송합니다.

- 선택한 이용내역 1건의 원본 16바이트 기록
- 해당 기록의 지역·노선·역 코드와 현재 해석 및 사용자가 제안한 해석
- 거래 유형, 이용 날짜, 잔액과 계산 금액
- 사용자가 제보 유형에 따라 입력한 역 이름·도시·노선, 버스 회사명·운행 도시/지역 또는 제보 설명
- 사용자가 직접 입력한 추가 설명
- 앱·파서·역 데이터베이스 버전
- 플랫폼과 OS 버전
- 앱에서 생성한 익명 제보 번호

전송된 내용은 오류 확인과 앱 개선을 위해 사용합니다.

### 별도 카드 인식 문의

일반 이용내역 제보와 별개의 선택 기능입니다. 진단 스캔에 동의한 뒤 시스템 코드, 제조 정보(PMm), 허용된 일부 서비스의 존재 여부와 통신 오류 코드만 기기에서 확인합니다. 카드 전체나 서비스 본문을 읽지 않습니다.

사용자가 전송 항목 미리보기·목적·보관 기간을 확인하고 별도로 명시적 전송 동의를 한 경우에만 다음 정보를 Supabase로 전송합니다.

- 시스템 코드·PMm·일부 서비스 존재/부재/확인 불가·통신 오류 종류
- 사용자가 입력한 카드 종류와 문제 설명(선택 사항)
- 앱/OS 버전·플랫폼·무작위 접수 번호·동의 문서 버전

목적은 카드 종류 구분과 읽기 오류 개선입니다. 이 문의에는 카드 IDm·카드번호·기기 고유 식별자·잔액·이용내역·전체 덤프를 포함하지 않습니다. 자유 입력란에도 이름·카드번호·연락처 등 개인정보를 입력하지 않도록 안내합니다. 문의 내용을 변경하면 전송 미리보기와 동의를 다시 확인합니다. 문의 전송 전에는 네트워크 전송하지 않으며 문의 화면을 나가면 앱에 내용을 남기지 않습니다.

카드 인식 문의도 동일한 익명 인증 기반 접수 제한을 적용합니다. 처리 완료(`RESOLVED`) 후 1년 뒤 월간 작업에서 삭제하며 검토 중인 문의는 유지합니다. 접수 번호를 통합 문의 이메일로 알려 삭제를 요청할 수 있습니다.

## 4. 전송하지 않는 정보

카드 IDm 원문, 선택하지 않은 다른 이용내역, 이름, 이메일 주소, 기기 고유 식별자, 현재 위치와 전체 이동 경로는 오류 제보 데이터에 포함하지 않습니다.

## 5. 외부 처리 서비스

오류 제보 접수에는 Supabase의 익명 인증, Edge Function과 PostgreSQL 데이터베이스를 사용합니다. 익명 인증 ID는 서버 내부에서 10분당 최대 5건 제한과 악성 제보 차단에만 사용합니다. 이 값은 이메일, 카드 IDm 또는 기기 고유 ID가 아니며 앱 화면에 표시하지 않습니다. 새 제보에서는 서버가 해당 익명 ID를 제보와 연결해 차단 상태를 확인할 수 있지만, 운영자 UI에는 UUID 자체를 표시하지 않습니다. 제보 내용은 서비스 제공 과정에서 Supabase 인프라를 통해 처리됩니다. 네트워크 연결 과정에서 발생하는 IP 주소 등의 기술 정보는 Supabase의 서비스 운영 및 보안 정책에 따라 처리될 수 있습니다.

## 5-1. Google 지도

철도 이용내역 상세를 열면 인터넷 연결·역 위치·지도 설정을 확인한 경우 Google Maps SDK 지도를 자동으로 표시합니다. 복합역·구간은 후보 위치를 표시합니다. 표시할 역의 좌표와 주변 지도 영역이 지도 요청에 사용됩니다. Google은 IP 주소, 기기·운영체제·SDK 정보, 지도 SDK 전용 가명 식별값, 진단·사용 정보를 처리할 수 있습니다. 현재 위치 권한은 요청하지 않으며 카드 IDm·카드번호·잔액·이용내역 원문을 지도 SDK에 전달하지 않습니다.

인터넷 연결이 확인되지 않으면 지도를 표시하지 않으며, 연결 후 지도 새로고침으로 다시 시도할 수 있습니다. 연결 상태는 Android 네트워크 기능 정보로 기기에서 확인하며 별도 확인 서버에 요청하지 않습니다. 지도 표시 중단이나 새로고침은 이미 발생한 지도 요청을 취소하거나 삭제하는 것은 아닙니다. 지도 연결 없이도 카드 읽기와 이용내역 목록은 사용할 수 있습니다. 앱은 지도 이용내역을 별도로 저장하지 않습니다. 외부 지도 서비스의 처리·보관·삭제 기준에는 [Google 개인정보처리방침](https://policies.google.com/privacy)이 적용됩니다. SDK 처리 항목은 [Google Maps SDK의 데이터 공개 안내](https://developers.google.com/maps/documentation/android-sdk/play-data-disclosure)를 참고할 수 있습니다. 역 좌표는 앱에 포함한 Wikidata CC0 자료를 사용하며 온라인 역 검색·경로 검색은 하지 않습니다.

## 6. 역 코드 데이터

역명 조회에는 사용 허가를 받아 앱에 함께 배포하는 Yoiko 역 코드 데이터를 사용합니다. 조회는 기기 안에서 수행되며, 역명을 확인하기 위해 카드 기록을 외부 서버로 보내지 않습니다. 데이터 출처와 이용 조건은 앱 설정의 데이터 출처 및 운임 기준 화면과 `assets/licenses/yoiko-station-data-TERMS.txt`에 표시합니다.

## 7. 보관과 삭제

기기에서 읽은 이용내역은 앱이 영구 저장하지 않습니다. 선택적으로 전송된 오류 제보 중 `APPLIED` 또는 `REJECTED`로 해결된 문의와 검토 이력은 해결 시점부터 1년간 보관한 뒤 매월 자동 삭제합니다. `RECEIVED`, `REVIEWING`, `VERIFIED` 문의는 미처리 제보가 사라지지 않도록 자동 삭제하지 않습니다. 악성 제보 차단에 쓰는 익명 인증 ID는 서버 보안 목적으로만 유지하며, 법령상 보존 의무가 있는 경우에는 해당 기간 동안 보관할 수 있습니다.

## 8. 이용자의 선택

오류 제보나 카드 인식 문의를 전송하지 않아도 NFC 읽기와 이용내역 확인 기능을 사용할 수 있습니다. 전송 전 화면에서 실제 전송 항목을 확인할 수 있으며, 해당 전송에 동의하지 않으면 제보·문의 데이터는 전송하지 않습니다. Google 지도는 위 5-1항에 안내한 조건에서 자동으로 연결되며, 지도 서비스의 데이터 처리는 제보·문의 전송과 별개입니다.
