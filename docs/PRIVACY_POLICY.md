# 일본 교통카드 리더 개인정보처리방침

- 시행일: 2026년 8월 10일
- 앱 버전: 1.0.0
- 운영자: 일본 교통카드 리더 운영자
- 공개 주소: <https://yohan020.github.io/ic_card_reader/>

## 1. NFC 사용 목적

앱은 사용자가 스캔을 시작했을 때 일본 교통계 IC 카드의 최근 이용내역을 읽기 위해 NFC 기능을 사용합니다. 앱은 카드에 정보를 기록하거나 변경하지 않습니다.

## 2. 기기 안에서 처리하는 정보

최근 이용내역의 원본 16바이트 기록, 날짜, 거래 유형, 역 코드·역명, 금액과 잔액을 기기 안에서 해석해 표시합니다. 이용내역은 영구 저장하지 않으며 다른 카드를 읽으면 현재 결과로 교체됩니다. 카드 IDm 원문은 NFC 통신 중에만 일시적으로 사용하고 저장·로그·화면 표시·서버 전송을 하지 않습니다.

## 3. 오류 제보 시 전송하는 정보

오류 제보는 선택 사항입니다. 사용자가 전송 전 미리보기를 확인하고 명시적으로 동의한 경우에만 다음 정보를 Supabase로 전송합니다.

- 선택한 이용내역 1건의 원본 16바이트 기록
- 해당 기록의 지역·노선·역 코드와 현재 해석 및 사용자가 제안한 해석
- 거래 유형, 이용 날짜, 잔액과 계산 금액
- 사용자가 제보 유형에 따라 입력한 역 이름·도시·노선, 버스 회사명·운행 도시/지역 또는 제보 설명
- 사용자가 직접 입력한 추가 설명
- 앱·파서·역 데이터베이스 버전
- 플랫폼과 OS 버전
- 앱에서 생성한 익명 제보 번호

전송된 내용은 오류 확인과 앱 개선을 위해 사용합니다.

## 4. 전송하지 않는 정보

카드 IDm 원문, 선택하지 않은 다른 이용내역, 이름, 이메일 주소, 기기 고유 식별자, 현재 위치와 전체 이동 경로는 오류 제보 데이터에 포함하지 않습니다.

## 5. 외부 처리 서비스

오류 제보 접수에는 Supabase의 익명 인증, Edge Function과 PostgreSQL 데이터베이스를 사용합니다. 익명 인증 ID는 서버 내부에서 10분당 최대 5건 제한과 악성 제보 차단에만 사용합니다. 이 값은 이메일, 카드 IDm 또는 기기 고유 ID가 아니며 앱 화면에 표시하지 않습니다. 새 제보에서는 서버가 해당 익명 ID를 제보와 연결해 차단 상태를 확인할 수 있지만, 운영자 UI에는 UUID 자체를 표시하지 않습니다. 제보 내용은 서비스 제공 과정에서 Supabase 인프라를 통해 처리됩니다. 네트워크 연결 과정에서 발생하는 IP 주소 등의 기술 정보는 Supabase의 서비스 운영 및 보안 정책에 따라 처리될 수 있습니다.

## 6. 역 코드 데이터

역명 조회에는 사용 허가를 받아 앱에 함께 배포하는 Yoiko 역 코드 데이터를 사용합니다. 조회는 기기 안에서 수행되며, 역명을 확인하기 위해 카드 기록을 외부 서버로 보내지 않습니다. 데이터 출처와 이용 조건은 앱의 오픈소스 라이선스 화면과 `assets/licenses/yoiko-station-data-TERMS.txt`에 표시합니다.

## 7. 보관과 삭제

기기에서 읽은 이용내역은 앱이 영구 저장하지 않습니다. 선택적으로 전송된 오류 제보 중 `APPLIED` 또는 `REJECTED`로 해결된 문의와 검토 이력은 해결 시점부터 1년간 보관한 뒤 매월 자동 삭제합니다. `RECEIVED`, `REVIEWING`, `VERIFIED` 문의는 미처리 제보가 사라지지 않도록 자동 삭제하지 않습니다. 악성 제보 차단에 쓰는 익명 인증 ID는 서버 보안 목적으로만 유지하며, 법령상 보존 의무가 있는 경우에는 해당 기간 동안 보관할 수 있습니다.

## 8. 이용자의 선택

오류 제보를 전송하지 않아도 NFC 읽기와 이용내역 확인 기능을 사용할 수 있습니다. 전송 전 화면에서 실제 전송 항목을 확인할 수 있으며, 동의하지 않으면 아무 정보도 전송하지 않습니다.
